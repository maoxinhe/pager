# 网站访问诊断工具

朋友在国内打不开你网站时,用这个页面定位到底卡在哪一层。

## 使用方法

打开 `https://maoxinhe.github.io/pager/`,输入打不开的域名,点「开始诊断」。

**关键**:必须在「打不开的那台设备 + 打不开的那个网络」下打开(不是你的网络),
否则测出来的结果没意义。约 30 秒出结论,点「复制报告」把结果发回即可。

## 访问链路四层

访问一个网站要连过四道关,换域名只影响其中两层:

| 层 | 环节 | 换域名管用吗 |
|---|---|---|
| 1 | DNS 解析 | 有用 |
| 2 | 权威 NS / 域名被污染 | 有用(唯一必换域名的场景) |
| 3 | 连 Cloudflare 边缘节点 | **没用,必须换 CDN** |
| 4 | TLS 握手 / SNI | 有用 |

第 3 层是最高概率的元凶:Cloudflare 免费版没有中国大陆节点,
104.16 / 172.64 / 162.159 / 188.114 等网段在国内三网被限速、丢包或阻断。
此时把 DNS 迁到腾讯云、但源站仍指向 Cloudflare,朋友依然打不开。
